// LEARNING PATH

From Beginner To Robot Programmer

This course is designed so students can start with zero experience and work toward building and troubleshooting a complete FRC robot.

PHASE 1
Java Fundamentals
Variables, methods, classes, constructors, objects, loops, conditionals, and problem solving.
PHASE 2
Robot Foundations
WPILib structure, robot loops, commands, subsystems, controllers, and SmartDashboard.
PHASE 3
Building Real Systems
Drivetrains, elevators, shooters, pneumatics, sensors, and debugging.
PHASE 4
Problem Solving
Learn how to debug, tune, organize, and improve robot code like a real competition team.
